Features

A calm place for loud agents.

Everything you need to direct, review and ship agent work, without juggling five terminals and three IDEs.

Threads

All your agents, one sidebar.

Every thread lives in one place, grouped by project. Pick the agent and model per thread. Claude on the UI, Codex on the review, Cursor on the docs, and switch between them in a keystroke.

  • Streaming replies with tools, plans and reasoning laid out clearly
  • Queue and steer messages while an agent works
  • Import existing Codex and Claude history
Review

See every change before it lands.

The Changes panel shows a live diff of what the agent touched, turn by turn. Bubble saves a hidden Git checkpoint around every turn, so you can rewind files and conversation together with Edit from here.

  • Per-turn and full-branch diffs
  • Checkpoints that never touch your branch history
  • Commit, push and open a PR with generated messages
Race

Race your models.

Not sure which agent will nail it? Send one prompt to several. Each racer gets its own Git worktree, so nothing collides. Compare the results, keep the best one in your checkout and discard the rest.

  • Racers start from your uncommitted changes
  • Live status for each racer, including approvals
  • Branches named bubble/race-…
Built in

Terminal, files and browser. Right there.

A real terminal, a file browser and a built-in browser sit next to the conversation. Pick an element or a region in the page and drop it straight into your prompt as context.

  • Multiple PTY terminals with history that survives restarts
  • Workspace file tree and content search
  • Browser element picking and annotations

Get started

Up and running in a minute.

    Install Bubble

    Use Homebrew, or download the .dmg and drag it to Applications.

  2. 2

    Sign in to an agent

    Bubble uses each CLI's own login. Sign in to at least one:

    claude auth logincodex logincursor-agent loginopencode auth login

    Open a folder

    Pick a project, choose an agent and start a thread. Bubble checks which agents are ready the first time you open it.

FAQ

Questions, answered.

Is it free?

Yes. Bubble Harness is free to download and use. It's an early preview, so expect rough edges, and please tell us about them.

Do I need API keys?

No. Bubble doesn't sell tokens. It runs the agents you already pay for through their own command-line tools and uses their existing logins. Your logins stay on your Mac.

Does my code leave my machine?

Only the way it already does when you use these agents directly: your prompts and code go to the agent you choose, nowhere else. Bubble has no account, no analytics and no server of its own. The only other request it makes is a daily check of GitHub releases for a new version, which you can turn off in Settings.

What do I need to run it?

An Apple Silicon Mac on macOS 11 or later, Node.js 22.12 or newer (Homebrew installs it for you), and at least one supported agent installed and signed in.

macOS says the app can't be opened.

Bubble isn't notarized by Apple yet. Open System Settings → Privacy & Security, scroll down and click Open Anyway. Installing with Homebrew avoids this.

Windows, Linux or Intel Macs?

Not yet. Apple Silicon Macs come first. Star the repo to hear when other platforms land.

Is it open source?

No. The source is private. The public repo holds releases, the changelog and the issue tracker.
